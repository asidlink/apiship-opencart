# Модуль расчёта доставки ApiShip для OpenCart 4.1.0.3

Модуль доставки (shipping) для CMS **OpenCart 4.1.0.3**: расчёт стоимости доставки
через сервис **ApiShip** (`https://apiship.ru`), выбор пунктов выдачи (ПВЗ) на
Яндекс.Картах и экспорт заказов в ApiShip.

## Возможности

- Расчёт стоимости доставки **до ПВЗ** (самовывоз) и **курьером** через API ApiShip.
- Выбор пункта выдачи на **Яндекс.Картах** (встроенная карта с фильтрами по типам ПВЗ и провайдерам).
- Логотипы служб доставки (СДЭК и др.) прямо в списке способов доставки.
- Выбранный ПВЗ отображается в способе доставки и является ссылкой для его смены.
- Группировка всех ПВЗ в один тариф «Доставка до ПВЗ» или отдельная карта для каждой СД.
- Экспорт заказов в ApiShip, отслеживание статусов, возвраты/отмены.
- Расширение итогов заказа **«Обрешётка»** (отдельная строка стоимости упаковки).

## Установка

1. Скопируйте папку `extension/apiship` в каталог `extension/` вашей установки OpenCart 4.1.0.3.
2. В админ-панели: **Расширения → Доставка (Shipping)** → нажмите «Установить» для **ApiShip**.
   (Создадутся таблицы `oc_apiship_order`, `oc_apiship_order_status`, зарегистрируется
   модуль доставки и расширение итогов «Обрешётка»).
3. Нажмите «Редактировать» и заполните настройки.

## Настройка

- **API token ApiShip** — токен из личного кабинета ApiShip.
- **Город/адрес отправки** — параметры точки отправки.
- **Контактные данные отправителя** — организация, ИНН, телефон, e-mail.
- **Шаблоны названий** — например `Доставка до ПВЗ %name`, `Доставка курьером`.
- **Группировка ПВЗ** — один тариф «Доставка до ПВЗ» (рекомендуется) или по одной карте на СД.
- **Обрешётка** — параметры добавки к габаритам и весу (расширение итогов `crate`).

## Совместимость

- OpenCart **4.1.0.3** (PHP 8.x).
- Модуль адаптирован под структуру OpenCart 4 (namespace `Opencart\Extension\Apiship\...`).
